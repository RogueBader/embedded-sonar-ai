# Embedded Sonar AI
 
Embedded AI project for acoustic echo detection and classification.
 
## Objectives
 
- Binary acoustic data acquisition
- DSP-based feature extraction
- PyTorch model training
- Embedded inference deployment
 
## Hardware
 
- Arduino UNO Q 4GB
- Qualcomm Dragonwing QRB2210
- STM32U585
 
## Status
 
Project initialization and software pipeline setup.
